# Sky and sea of Hilo

Interactive explainers, published at https://fbremer.github.io:

- [Why the latest sunrise comes after the shortest day](https://fbremer.github.io/hilo-sunrise-drift.html)
- [The figure 8 the Sun draws over Hilo](https://fbremer.github.io/hilo-analemma.html)
- [Why Hilo's tides rise and fall the way they do](https://fbremer.github.io/hilo-tides.html)
- [How tides stretch the sea, slow the Earth and push the Moon away](https://fbremer.github.io/tidal-forces.html)

Each page is one self-contained HTML file with no build step. The sun pages use standard solar-position approximations. The tide page sums NOAA's 16 largest harmonic constituents for Hilo (station 1617760) with nodal corrections.

`checks/` compares the pages with primary sources. Made with AI assistance. Not for navigation.
